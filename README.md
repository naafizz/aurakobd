# AURAKO — Luxury Korean Skincare eCommerce Template

A complete, static, vanilla HTML/CSS/JS eCommerce front-end for a
premium Korean skincare brand. No frameworks, no build step — upload
the folder as-is to GitHub Pages (or any static host) and it works.

## What's included
- 19 fully built pages: Home, Shop, Category, Product Details, Cart,
  Checkout, Order Success, Track Order, Wishlist, About, Contact, FAQ,
  Privacy, Refund, Shipping, Terms, Journal (blog list + post), 404
- 250 demo products, 15 brands, 25 blog posts, 20 testimonials
  (`assets/data/*.json`, generated by `generate-data.js`)
- Cart + wishlist powered by `localStorage`, shared across every page
- Cash on Delivery checkout wired to **Firebase Firestore** (free
  Spark plan), with an automatic `localStorage` fallback so the demo
  works with zero setup — see `FIREBASE-SETUP.md` to go live
- Hero carousel, quick view modal, live search, product filtering/
  sorting/pagination, order tracking with a status timeline, reveal-
  on-scroll animations, skeleton loading, and a responsive layout for
  mobile/tablet/laptop/desktop/ultra-wide

## Structure
```
index.html, shop.html, category.html, product.html, cart.html,
checkout.html, order-success.html, track-order.html, wishlist.html,
about.html, contact.html, faq.html, privacy.html, refund.html,
shipping.html, terms.html, blog.html, blog-post.html, 404.html

assets/
  css/        core.css · components.css · animations.css · responsive.css
  data/       products.json · brands.json · categories.json · blogs.json · testimonials.json
  images/     (empty — product imagery is pulled from picsum.photos placeholders)
  icons/      (empty — reserved for custom icon assets)

generate-data.js     regenerates the demo data (run with `node generate-data.js`)
FIREBASE-SETUP.md    step-by-step guide to connect real Firestore storage
```

## Running locally
This is a static site, but the JSON data is loaded via `fetch()`, which
most browsers block on `file://` URLs. Serve it with any static server:

```bash
npx serve .
# or
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploying to GitHub Pages
1. Push this folder to a GitHub repo.
2. In the repo's **Settings → Pages**, set the source to the branch
   root (or `/docs` if you move it there).
3. Your site will be live at `https://<username>.github.io/<repo>/`.

## Notes on demo data
Product photography uses [picsum.photos](https://picsum.photos) seeded
placeholders so every one of the 250 products has a unique, consistent
image without needing real product photography. Swap these for real
photos by editing `assets/data/products.json` (or rerun
`generate-data.js` after adjusting the image logic).
